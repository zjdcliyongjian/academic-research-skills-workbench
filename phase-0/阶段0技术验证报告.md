## 2. App Server 验证

### 2.1 官方接口边界

OpenAI Docs 将 App Server 定义为把 Codex 嵌入自有产品的接口，覆盖认证、会话历史、审批和流式 Agent 事件：

- [Codex App Server 官方文档](https://developers.openai.com/codex/app-server/)
- 稳定主通道：`stdio://`，JSONL 承载 JSON-RPC 消息。
- WebSocket：实验性且官方标记为不支持生产使用，因此不进入 MVP 主链路。
- 客户端生命周期：`initialize → initialized → thread/start 或 thread/resume → turn/start → 流式事件 → turn/completed`。

`openai-docs` Skill 使本阶段采用了官方推荐的本地 `stdio` 集成，而没有把实验性 WebSocket 写成正式架构。

### 2.2 本机协议验证

本机命令成功生成当前 Codex 版本对应的 JSON Schema：

```powershell
codex app-server generate-json-schema --out .\evidence\schemas
```

Schema 中已确认以下稳定能力：

- `skills/list`
- `thread/start`
- `thread/read`
- `thread/resume`
- `thread/name/set`
- `turn/start`
- `item/agentMessage/delta`
- `item/commandExecution/requestApproval`
- `turn/completed`

### 2.3 可复跑样例

```powershell
node .\app-server-smoke.mjs
```

该脚本会：

1. 启动独立 `codex app-server --listen stdio://` 子进程。
2. 完成客户端握手。
3. 强制刷新 Skill 列表。
4. 校验 12 个科研 Skill。
5. 在只读沙箱创建真实 Codex 任务。
6. 显式附加 `idea-evaluator`。
7. 接收流式事件和最终结果。
8. 将完整事件写入 JSON 证据文件。

最新 Skill 测试输出：


## 4. 审批链路验证

可复跑命令：

```powershell
node .\approval-smoke.mjs
```

测试步骤：

1. 创建 `sandbox=read-only`、`approvalPolicy=on-request` 的任务。
2. 要求 Codex 尝试在隔离测试目录创建探针文件。
3. App Server 发出 `item/commandExecution/requestApproval`。
4. 测试客户端返回 `{ "decision": "decline" }`。
5. Codex 停止写入，探针文件未出现。

这证明 MVP 可以把审批请求转换为工作台中的“允许、仅本次允许、拒绝、取消”交互，并在用户拒绝后保持原始资料不变。

### 5.2 工作台实现

```powershell
.\open-codex-thread.ps1 -ThreadId 01a09e0a-804c-7453-bcab-b9edcf97bf84
```

正式后端需要：

1. 只接受 UUID 格式的 `thread_id`。
2. 先检查 `codex:` 协议是否注册。

4. 若失败，显示“复制任务 ID”和“打开 Codex 首页”降级入口。

## 7. 发现的问题与设计修正

### 7.1 Skill 上下文预算

问题：本机 Skill 数量较多，描述可能被压缩。

修正：采用“阶段白名单 + 单次显式附加”，不依赖自然语言自动匹配全部 Skill。

### 7.2 App Server 版本耦合

问题：协议 Schema 与 Codex CLI 版本绑定。

修正：工作台首次启动和升级后重新生成或校验 Schema；不识别的事件落入兼容日志，不静默丢弃。

### 7.3 Codex 深链属于桌面能力

问题：深链虽已在当前版本验证，但不是网页自身能力。

修正：启动时检查 Windows 协议注册；失败时显示真实降级方案，不保留无效按钮。

### 7.4 App Server 任务与桌面任务共享

结果：App Server 创建的非临时任务能直接出现在 Codex 桌面任务列表并被恢复。这一结果支持“内嵌工作台操作 + 一键回到 Codex 深度处理”的双入口设计。
